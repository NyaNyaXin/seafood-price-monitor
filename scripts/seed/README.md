# 种子数据（可选）

`init_pg.py --seed` 读取本目录的三个 JSON，用于**空库重建后让看板立刻有内容**，
或离线演示。业务上不是必需品 —— 趋势是平台现成的 30 天窗口，直接跑一次
`fetch.py` 也能拿到。

| 文件 | 内容 | 当前行数 |
|---|---|---|
| `price_obs.json` | 市场当日快照（59 市场白名单里的冻品） | 128 |
| `spec_snapshot.json` | 品种分规格价（全国 / 辽宁） | 76 |
| `product_trend.json` | 品种 30 天趋势（全国 / 辽宁） | 1131 |

## 约定

- **不含 `id`**：入库时由 `SERIAL` 重新分配，所以可在任意库重建。
- **不含 `fetch_log`**：采集流水属于运行时记录，重建后从空开始。
- **是快照，会过时**：行数是 2026-11-24 导出时的值，随日常采集增长，不必对齐。
- 导入走 `db.upsert_*`，唯一键幂等，**重复导入不会重复插入**。

## 重新生成

```bash
python scripts/init_pg.py --dump-seed     # 从当前库覆盖导出本目录三个文件
```

> 生成前请确认库里的数据是干净的。2026-11-24 曾清理过 52 条「未来日期」脏数据
> （`parse_md_date` 年份推断缺陷，备份在 `data/archive/future-dates-2026-11-24.json`），
> 导出种子时该缺陷已修复。
