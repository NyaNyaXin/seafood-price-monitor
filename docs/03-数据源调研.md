> 版本 v1.0 · 2026-11-23 · 全部结论来自当日实测（HTTP 状态、返回条数、字段结构），非推测。

## 1. 结论摘要

| 结论 | 依据 |
|---|---|
| **已把「水产时价云」从辽宁扩到全国 59 个市场**，冻品日采集量 15 → **120 条**（8 倍），覆盖市场 2 → **30 个** | 同接口 `rid=0` 全量 1047 条，`pageSize=500` 3 次请求拉完 |
| **不需要新数据源就能显著扩容**：全国市场、45 个冻品品种、30 天趋势都在同一个公开接口里 | 实测 `GetPriceNow` / `GetPriceList` / `GetCategorys` |

| **官方周报可作为「全国基准价」**：7 种水产品周均价，agri.cn 页面可直接解析 | 列表页 23 篇文章可抓，正文含水产品段落 |

| **`GetVolumeList` 没有成交量**，只有均价+趋势，名字误导 | 返回体字段为 `priceAll/price30All/rateAll` |

## 3. 逐源详情

### 3.1 水产时价云（已在用，本次扩容）

- 基址 `http://znyj.nftec.agri.cn:8089`，公开 token `0000000000000000`，无 CORS。
- `GET /API/Product/GetPriceNow?rid=0&PageNum=N&pageSize=500`
  - `rid=0` = 全国；实测 `TotalItemCount=1047`、`TotalPageCount=3`（pageSize=500）。
  - **pageSize 上限实测 ≥500**，全量只需 3 次请求，成本可忽略。
  - 59 个市场，按冻品规则过滤后 120 条 / 30 个市场。
  - `unit_id` 过滤参数无效（传了不生效），必须全量拉回本地过滤。
- `GET /API/Product/GetPriceList?rid=4&pid={品种}`：分规格 + 30 天趋势（全国/辽宁双线）。
- `GET /API/Product/GetCategorys`：375 品种，7 大类（海水鱼/淡水鱼/虾蟹/贝类/头足/藻类/其他）。
- `GET /API/Product/GetVolumeList?rid=4&pid={品种}`：**名不副实**，返回 `priceAll/price30All/rateAll/standar/trend`，无成交量字段。

**风险**：平台对进口鱼/虾贝类品种有 16–25s 固定慢查询（详见需求文档 §2.1），非限流。全量快照接口无此问题（0.08s）。

### 3.2 农业农村部 全国农产品批发市场价格信息系统（pfsc）

- 前端 Vue SPA，接口在 `/api/priceQuotationController/*` 与 `/price_portal/*`。
- **可用**：
  - `GET /price_portal/sys-user-relation/getVarietiesTree` → 国家标准品种树，含 `AM 水产品`（AM01 淡水鱼 / AM02 海水鱼 / AM03 虾蟹及两栖类 / AM04 螺贝及软体类 / AM05 海水植物 / AM07 水产加工品 / AM08 加工副产品 / AM99 其他）。
  - `POST /api/priceQuotationController/getMarketByProvinceCode?provinceCode=xx` → 全国批发市场名录（marketCode / marketName）。
- **不可用**：价格明细 `pageList` 需要 `validateCode` + `interfaceCode`（图形验证码），前端代码里明确有「请填写验证码」分支。**不要尝试绕过**，既不稳定也不合规。

**定位**：品种分类标准与市场名录的权威校准源；价格数据不接。

### 3.3 农业农村部 周报（建议接入）

- 列表页 `https://www.agri.cn/sj/jcyj/` 可解析，23 篇文章，含「2026年第N周国内外农产品市场动态」。
- 正文水产品段落形如：
  > 白鲢鱼、鲫鱼和花鲢鱼批发市场周均价每公斤分别为 10.16 元、19.55 元和 16.64 元，环比分别涨 1.4%、0.3% 和 0.1%；草鱼、大带鱼、大黄花鱼和鲤鱼…分别为 16.76 元、39.60 元、42.85 元和 13.85 元…
- 7 个固定品种：草鱼、鲫鱼、鲤鱼、白鲢鱼、花鲢鱼、大带鱼、大黄花鱼。
- `zdscxx.moa.gov.cn:8080` 的详情页正文是 JS 渲染（标题可取、正文空），**用 agri.cn 抓**。

**价值**：唯一的「官方口径全国均价」，周频，可用于计算沈阳/辽宁相对全国的溢价或折价。

### 3.4 北京新发地（可选）

- `POST http://www.xinfadi.com.cn/getPriceData.html`，表单 `prodPcatid=1190&limit=N&current=1` 取水产大类。
- 实测当日 113 条，子类：淡水鱼 / 海水鱼 / 虾蟹类 / 贝壳类 / 其他类（`prodPcatid` 传子类 ID 无效，只能传大类 1190）。
- 字段：`lowPrice/highPrice/avgPrice`、`specInfo`（如 `750g-1000g`）、`unitInfo`（**斤**）、`place`（产地）、`pubDate`。
- **全部鲜活，没有冻品**；单位是斤不是公斤。

**风险**：口径与本项目不同（鲜活 vs 冻品、斤 vs 公斤、北京 vs 沈阳）。若接入必须独立表/独立标识，**不得与冻品序列混绘一条线**。

## 6. 接入红线（避免踩坑）

1. **同一「市场+品种+规格」才是一条曲线**。跨市场不要合并成一条线，跨形态（鲜活/冻品）更不能。
2. **单位必须归一**。新发地是「斤」，本系统是「元/kg」，入库前乘 2；反向展示时再除。
3. **不要为验证码类接口写绕过**。pfsc 价格明细有图形验证码，属于明确的反自动化措施。
4. **新增源必须能写进 `shared/reference.json`**，不允许在 Python 或 TS 里硬编码第二份市场/品种清单。
5. **所有外部源失败不得中断采集**。单源失败记日志后继续，与现有 `fetch_log` 约定一致。
